# F08 — Moderator live-stage operation

Target specification. Inherits [shared flow contract](../USER_FLOWS.md#shared-flow-contract-and-state-vocabulary),
[UI/recovery requirements](../UI_UX.md#shared-ui-state-and-recovery-contract) and
[evidence matrix](../USER_FLOWS.md#evidence-matrix-for-each-delivered-flow).
[Flow index](../USER_FLOWS.md) · [Delivery gates](../../DEVELOPMENT_PLAN.md).


- **Actor / prerequisites:** assigned event moderator with explicit stage
  permissions, valid schedule/judge readiness, connection/recovery plan and rehearsal.
- **Entry / screens:** S14 stage/session selector → live console; invitation F06.
- **Happy path:** select permitted stage → confirm current/next identity and server
  revision → inspect judge completion → perform allowed start/advance/pause/skip
  command → receive acknowledgement → update queue/completion for all clients.
  Exceptions/reopen need authorized reason and audit under live/scoring decisions.
- **Validation / permissions:** exact event/stage/revision and transition checked
  transactionally; completion comes from acknowledged sheets; moderator role must
  not reuse score.submit to gain stage authority or expose unauthorized values.
- **Alternate / failure:** missing sheets/judges blocks according to agreed override
  policy; simultaneous operators receive conflict/current state; uncertain command
  disables repeat until reconciliation. Reopened scoring explicitly changes readiness.
- **Loading / empty:** queue load; no runnable schedule → organizer next step;
  waiting/paused state explicit, no fabricated current performance.
- **Cancel / recovery:** exception confirmation cancel leaves queue unchanged;
  offline/stale connection banner, stop unsafe writes, invoke manual fallback;
  reconnect refetches queue, permissions and command outcome before enabling controls.
- **Result / stages:** acknowledged queue transition and audit; proposed live/queue
  statuses require ADR-003, never repurpose DATA_REVIEW/FINALIZED labels.
- **Dependencies:** P6-LIVE-MODEL/SCORING-MODEL/MODERATOR/RECOVERY, P4-STAFF,
  transactional commands/completion DTO and chosen delivery transport, manual runbook.
- **Acceptance:** repeated taps and lost response cause at most one transition;
  wrong stage/permission/stale version cannot advance; touch/keyboard work under
  rehearsal time pressure; reconnect and manual recovery preserve acknowledged work.
